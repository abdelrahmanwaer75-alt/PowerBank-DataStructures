# PowerBank Data Structures – CSE111

Standalone Java 17 starter project. Each package groups related classes.
Compile from the project root:
`javac -d out $(find src/main/java -name "*.java")`
Run:
`java -cp out powerbank.Main`

This is an architecture/scaffold: TODO items must be completed and tested before submission. The CSE111 handout lists Clinic Appointment, Campus Lost and Found, and Event Ticketing; get instructor approval before using PowerBank Stations as an alternative.
